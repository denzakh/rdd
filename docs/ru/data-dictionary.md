# Data Dictionary (словарь данных)

Автогенерируемый словарь данных регистра. Страница **`/data-dictionary`** рендерит
таблицу «поле → тип → допустимые значения → источник в БД» напрямую из реестра
полей — единственного источника правды приложения.

## Как это работает

- Источник: `src/shared/config/registry` (`REGISTRY` — 6 разделов: паспорт
  пациента, контроль фазы, ремиссия, психический статус, терапия, шкалы).
- Сборка данных: `buildDataDictionary()` в
  `src/shared/lib/registry/data-dictionary.ts`. Для каждого поля реестра
  (`RegistryField`) вычисляет:
  - `id`, `label` (ru) — из реестра;
  - `db_type` и соответствующий SQL-тип D1 (`DB_TYPE_TO_SQL`: `BOOLEAN` →
    `INTEGER` (0/1), `DATE` → `TEXT` (ISO-8601), `FLOAT` → `REAL`);
  - допустимые значения: `options` (кодирование), `min`/`max` (диапазон), для
    `BOOLEAN` — 0/1;
  - источник в БД: `patients.<id>` (scope `patient`), `phases.<id>` (scope
    `phase`) либо «не хранится» для вычисляемых полей (`calculate`).
- Страница: `app/data-dictionary/page.tsx` (server component, `requireUser()`).
  Ручных описаний нет — словарь всегда синхронен с реестром и генерируемой
  D1-схемой (`npm run gen:d1`, `./matrix.md`, `./rdd-v1.md`).

## Правила чтения таблицы

- **NULL** — значение признака не заполнено (колонки создаются как `NULL`).
- «только текущий статус» — поле с `is_current_only`: доступно лишь в колонках
  98 (текущий статус) и 99 (выход) матрицы.
- «вычисляемое» — поле без колонки в БД, значение рассчитывается на лету
  (`src/shared/api/with-computed`), например `current_age`, `age_group`,
  `hamd_severity`.
- «deprecated с vN» — поле выведено из употребления protocol amendment'ом
  (`deprecated_since` в реестре, ./schema-evolution.md §3, §6): колонка
  остаётся в схеме и читаема, словарь показывает пометку, молча не удаляется.
- Кодирование категориальных значений — числовые коды `options` из реестра;
  они же используются при экспорте для биостатистики.
