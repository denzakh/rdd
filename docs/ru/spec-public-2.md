# Спека public-2: приватный хаб и курированная документация (вариант A, PR2)

**Статус:** спека · **Зависимости:** public-1 (публичные `/`, `/about`, `getCurrentUserSafe`, словари `landing/about`)
**Слои FSD:** `src/widgets/home-hub`, `src/shared/ui/top-navigation.tsx`, `src/shared/lib/intl/dictionaries`, `app/page.tsx`, `app/docs/page.tsx`, `app/layout.tsx`
**Цель:** залогиненный на `/` видит рабочий хаб вместо редиректа; появляется приватный `/docs` — 4–5 курированных карточек-выжимок со ссылками на GitHub, а не зеркало всех md. Портфолио-цель закрыта, операционка не светится.

## 2. Роуты PR2

| Роут     | Доступ                  | Содержимое                                                  |
| -------- | ----------------------- | ----------------------------------------------------------- |
| `/`      | ветвление               | гость → `<Landing/>` (PR1), юзер → `<HomeHub user locale/>` |

| `/about` | public                  | без изменений из PR1                                        |

## 3. Состав `/docs`

1. `Архитектура (выжимка)` → ссылка на GitHub `architecture-overview.md`;
2. `Безопасность (угроза → мера → где)` → ссылки на `auth.md + threat-model.md`;
3. `NFR / RTO / RPO (выжимка)` → ссылка на `nfr.md`;
4. `Roadmap: spec-stage-1..4 ✅` → ссылка на `roadmap.md`;
5. `Словарь данных (живой)` → внутренняя ссылка на `/data-dictionary` (единственный пример registry-driven в рантайме, не пересказывать).

## 4. Виджет home-hub

`src/widgets/home-hub/ui/home-hub.tsx` + `src/widgets/home-hub/index.ts`:

- приветствие `displayName · role` (данные уже есть из `getCurrentUserSafe`, новых запросов нет);
- 4 карточки-ссылки с одним предложением каждая;
- форма поиска `action="/patients" method="get" input name="q"`;
- для `role=readonly` — строка `readOnly` из словаря `common` (мутации и так закрыты `canWrite()` в Server Actions, дублировать проверки не надо).

## 5. Критерии приёмки

1. Матрица 2×2 (гость/юзер × ru/en): гость на `/` видит лендинг, юзер — хаб; `/docs` гостя редиректит на `/login`, юзера пускает.
2. Поиск из хаба ведёт на `/patients?q=...` и показывает тот же список, что прямой заход.
3. `must_change_password=1`: поведение как раньше — `requireUser()` в `/docs` уводит на `/change-password` (регрессии нет).
4. В `/docs` нет встроенных полных текстов `deployment/auth/threat-model`; только выжимки + внешние ссылки на GitHub.
5. `npm run lint`, `npx tsc --noEmit`, `npm run steiger`, `npm run build` — зелёные; валидатор FSD не ругается на новые `widgets/*`.
6. `public/robots.txt` из PR1 не менялся: `/docs` закрыт от индексации.
