# Дорожная карта развития RDD (docs/roadmap.md)

**Назначение:** сводный план доработок после v1 (registry core + auth + демо-матрица готовы).
Каждый этап имеет отдельную спеку: `spec-stage-1.md` … `spec-stage-4.md`.

| Этап                            | Спека             | Суть                                                                        | Статус       |
| ------------------------------- | ----------------- | --------------------------------------------------------------------------- | ------------ |
| 1. Реальные мутации данных      | `spec-stage-1.md` | Server Actions сохранения фаз, CAS-конфликты, аудит с actor_id              | спека готова |
| 2. Сущности и страницы пациента | `spec-stage-2.md` | Слой `entities`, страницы пациента, привязка матрицы к patient_id, агрегаты | спека готова |
| 3. Auth v1.5                    | `spec-stage-3.md` | Смена пароля, rate-limit, admin-UI, инвайты                                 | спека готова |
| 4. Качество и инфраструктура    | `spec-stage-4.md` | Тесты, CI, README, актуализация docs                                        | спека готова |

Порядок строгий: этап 1 снимает статус «demo» с матрицы и является блокером для всего остального.
